v2 Architecture

6 High-Signal Workflow Tools

Streamlined from monolithic wrappers into focused, high-precision tools designed specifically for AI agent tool calling.

pagespeed_analyze_page Read-Only

Full Lighthouse analysis for one public page. Supports modes: summary, recommendations, full, and performance-map (with Mermaid diagrams).

params: url, strategy, categories, report, runs, locale
pagespeed_diagnose_page Read-Only

Deep-dive into one focused diagnostic lens: render-blocking, javascript, images, network, elements, visual, or third-parties.

params: url, focus, strategy, responseFormat
pagespeed_get_field_data Read-Only

Real-world Core Web Vitals from Chrome UX Report (CrUX). Queries 28-day 75th-percentile field metrics by exact page URL or entire origin fallback.

params: url, scope (page|origin), formFactor
pagespeed_compare_pages Regression

Direct delta comparison between two URLs (staging vs prod) or measure a URL against a stored local baseline with multi-run statistical guarantees.

params: mode (pages|baseline), url, against, runs
pagespeed_analyze_batch Batch

Analyze 1 to 10 URLs in parallel with concurrency rate limiting and live progress reporting. Ideal for PR CI checks and site-wide triaging.

params: urls[], strategy, categories, report
pagespeed_clear_cache Lifecycle

Instantly purge this MCP server instance's in-memory response cache to force fresh telemetry fetching after deploying performance fixes.

params: (none)
